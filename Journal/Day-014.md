# ❌ Mistakes I Made

### 1. Rock Paper Scissors Logic

Some win/lose conditions were incorrect.

For example:

```python
elif user_answer == 2 and computer_answer == 1:
    print("You win!")
```

Rock beats Scissors, so this should have been **You lose**.

---

### 2. Infinite Loop Bug

In multiple places I accidentally wrote:

```python
is_on == False
```

instead of

```python
is_on = False
```

Using `==` compares values instead of assigning one.

---

### 3. Password Generator

The password generator only worked when the randomly generated counts happened to equal the requested password length.

This approach was inefficient because it relied on luck.

A better solution would be to repeatedly add random characters until the password reaches the required length, then shuffle them.

---

### 4. Number Guessing Game

Again, I used

```python
is_on == False
```

instead of

```python
is_on = False
```

The game wouldn't exit after guessing correctly.

---

### 5. Small Testing Mistakes

A few bugs remained because I didn't fully test every branch before considering the project complete.

---

# 🛠 How I Fixed Them

- Corrected the Rock Paper Scissors win/lose conditions.
- Replaced accidental `==` with `=` where variables needed updating.
- Planned a better password generation algorithm instead of relying on random sums.
- Tested programs more carefully before committing.
