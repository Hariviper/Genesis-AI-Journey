## Mistakes I Made

### 1. Reused variable names

I reused the variable name "key" inside nested loops.

Although it worked, it reduced readability.

Lesson:
Use meaningful variable names like:

student_name

details

field

value

---

### 2. Invalid menu condition

I wrote

if choice != "A" or choice != "B"

which is always True.

Correct approaches are:

if choice not in (...)

or

multiple != conditions joined with AND.

This mistake has appeared before, so I need to consciously avoid repeating it.

---

### 3. Forgot .items()

In my Phonebook project I wrote

for key, value in dictionary

instead of

for key, value in dictionary.items()

Lesson:

Dictionary iteration defaults to keys only.

---

### 4. Wrong data type

While updating a weapon name, I accidentally converted the input
to int() before calling .lower().

Weapons are strings, not integers.

Lesson:

Always think about the expected data type before converting input.

---

### 5. Duplicate menu output

I accidentally printed the same menu twice.

Small issue, but proofreading before running the program helps.
