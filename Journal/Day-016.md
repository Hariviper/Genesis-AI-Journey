# 📘 Day 16 Journal -- Exception Handling

## Goal

Learn how to write programs that don't crash by using Python exception
handling.

## Topics Learned

- `try` -- Wrap risky code.
- `except` -- Catch specific exceptions.
- `else` -- Runs only if no exception occurs.
- `finally` -- Always runs.
- `raise` -- Create your own exceptions for invalid situations.

## Mini Projects

- Safe Calculator

## Challenges

- Student Marks Validator

## Biggest Lessons

1.  Wrap only the code that can actually fail.
2.  `raise` creates an exception; `except` handles it.
3.  Keep functions focused on one responsibility.
4.  Validate inputs before processing t mkhem.
