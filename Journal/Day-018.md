## Tuples

A tuple is an ordered collection that cannot be modified after creation.

Example:

```python
movies = ("The Conjuring", "Insidious", "Fast Five")
```

I learned:

- Accessing items using indexing
- Negative indexing
- len()
- Tuples are immutable

---

## Sets

A set is an unordered collection of unique values.

Example:

```python
languages = {"Python", "Java", "Python"}
```

Output:

```
{"Python", "Java"}
```

Duplicate values are automatically removed.

I learned:

- add()
- remove()
- Union (|)
- Intersection (&)
- Difference (-)
