# ❌ Mistakes I Made

### 1. Forgot the exact exception name

I knew opening a missing file would cause an error but forgot that the exception is:

```python
FileNotFoundError
```

---

### 2. Didn't log enough information

The login logger only stored:

```
Login Failed
```

It should also save:

- Username
- Success / Failure
- Date
- Time

---

### 3. Forgot `.txt` extensions

Some files were created like:

```
student_record
shopping_list
```

Instead of:

```
student_record.txt
shopping_list.txt
```

---

### 4. Used

```python
remove(temp_list[-1])
```

instead of the cleaner

```python
pop()
```

---

# 🛠 How I Fixed Them

- Learned the correct exception name: `FileNotFoundError`.
- Will always include `.txt` when creating text files.
- Will use `pop()` when removing the last item from a list.
- Will improve logging by storing usernames, status, and timestamps.
