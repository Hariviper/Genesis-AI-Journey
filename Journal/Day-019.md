# What I Learned

Today I entered Object-Oriented Programming.

Instead of creating dozens of unrelated variables, I learned that I can create a Class, which acts as a blueprint.

Every object created from that class has its own copy of the attributes.

Example:

Class -> Warlord

Objects ->
Mihawk
Crocodile
Doflamingo

Instead of writing:

mihawk_name
mihawk_weapon
mihawk_haki

I can simply create one class and generate as many objects as I need.

I also understood that:

**init**()

runs automatically whenever an object is created.

I understood that:

self

refers to the current object.

If I create:

mihawk = Warlord()

then

self.weapon

actually belongs to Mihawk.

If I create

shanks = Warlord()

then self now refers to Shanks.
